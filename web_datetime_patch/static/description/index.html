Odoo Web Client Patch

Keep the year visible in localized dates and datetimes

Web Datetime Year Patch is a lightweight Odoo 19.0 module that makes the web client include the year whenever it formats localized dates or datetimes. It helps prevent ambiguous display formats without changing your data or requiring any configuration.

What it does

Odoo's web client relies on Luxon for localized date and datetime rendering. In some locales and widget combinations, the year may be omitted from the displayed value. This module patches the formatter at runtime so the year is always present.

  • Ensures localized date and datetime strings include the year.
  • Applies in the backend web assets bundle only.
  • Leaves the original format object untouched by using a shallow copy.

Highlights

Odoo 19.0 Backend only No setup required Lightweight patch No models

The module depends only on web and is designed to be easy to install, update, and maintain.

How it works

The module overrides Luxon's DateTime.toLocaleString() in the browser. If Odoo passes a format object without a year, the patch adds year: 'numeric' before delegating back to the original formatter.

This is a display-level fix only. It does not modify stored dates, business logic, or server-side values.

Installation

  • Add the module to your Odoo addons path.
  • Update the app list.
  • Install Web datetime year patch.

Once installed, the patch is applied automatically in the backend.

Compatibility

This module is built for Odoo 19.0 and targets the web client only. It is intended for projects where keeping the year visible improves clarity in record lists, forms, and date-related widgets.
